# Крылья Родины

Скрипты для скачивания и обработки номеров журнала "Крылья Родины"

## Найти новые номера

Поиск новых номеров на https://www.kr-magazine.ru/archive/ (список: `lib/pdfs.json`)

```bash
./bin/discovery.js            # проверить последний год
./bin/discovery.js --all      # проверить все годы
./bin/discovery.js --write    # добавить найденные в lib/pdfs.json
```

## Скачать PDF

Скачивает только отсутствующие в `pdf/` файлы

```bash
./bin/download.js
```

## Создать *.md

Конвертация PDF -> Markdown на pdf.js (`pdfjs-dist`), без внешних утилит:

```bash
npm install
./bin/md.js                  # pdf/*.pdf -> md/*.md (только новые)
./bin/md.js -j 8 --force     # пересоздать все, 8 параллельно
./bin/md.js pdf/KR_2026_9_10.pdf
./bin/md.js --no-pages       # без маркеров <!-- page N -->
```

- порядок чтения по дереву структуры PDF (InDesign tagged PDF): колонки, врезки, подписи
- колонтитулы и номера страниц удаляются
- переносы (мягкие и ручные) склеиваются по словарю документа
- заголовки `#`, **жирный**, *курсив*, подписи по шрифтам и кеглю
- разрядка (`С О Д Е Р Ж А Н И Е`) и сломанные ToUnicode шрифтов (`�`) исправляются

## Создать *.txt

Создание текстовых файлов из PDF (pdftotext)

```bash
./bin/txt.js
```
